Decompresses FlateDecode streams, parses Tj/TJ text operators, and inspects page counts using Android's native PdfRenderer.

Strictly Grounded AI

System prompts enforce strict grounding in your notes. If an answer isn't in your document, OmniNote AI politely informs you.

Room DB Persistence

Fast, offline-first SQLite database storing note titles, extracted text, and timestamps locally on your device with full privacy.

How to install the APK on Android

1

Download the compiled APK

Click "Download Android APK" above or go to the Actions tab on your GitHub repository to download the OmniNote-AI-APK artifact built by GitHub Actions.

2

Allow Installation

Open the downloaded .apk file on your Android phone. If prompted by Android security, enable "Install unknown apps" for your browser or file manager.

3

Launch OmniNote AI

Tap "Install" and open OmniNote AI! Create notes, import PDFs from your device, or load the built-in sample notebook to start asking grounded questions.
